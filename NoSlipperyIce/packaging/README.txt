NoSlipperyIce
Removes the Slippery Ice cataclysm from The Slormancer.

REQUIREMENTS
  The Slormancer on Steam (Windows, 64-bit)
  Microsoft Visual C++ 2015-2022 Redistributable (x64). Most PCs already
  have it. If the mod does not load, install it from
  https://aka.ms/vs/17/release/vc_redist.x64.exe

INSTALL
  1. Back up your save: %LocalAppData%\The_Slormancer
  2. Open the game folder
     (Steam: right-click the game > Manage > Browse local files)
  3. Extract this zip into it, so version.dll sits next to
     "The Slormancer.exe"
  4. Start the game from Steam as usual

USE
  Nothing to set up. Slippery Ice no longer covers the floor or makes
  you slide, wherever it would come from: cataclysm breaches, places of
  the Netherworld that always have it, and The Great Forge.

UNINSTALL
  Delete mods\Aurie\NoSlipperyIce.dll from the game folder. To remove
  the mod framework too, when no other mod uses it, also delete:
    version.dll
    NoSlipperyIce-README.txt
    aurie.log
    the mods folder
  The game's own files are never changed.

FILES IN THIS ZIP
  version.dll                      loads the mod framework when the game starts
  mods\Native\AurieCore.dll        Aurie Framework
  mods\Aurie\YYToolkit.dll         YYToolkit
  mods\Aurie\NoSlipperyIce.dll     the mod
  mods\licenses\                   licenses and sources of the above
